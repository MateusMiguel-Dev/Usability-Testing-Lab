# Usability Testing Lab

Laboratório interativo para registrar sessões de teste de usabilidade, organizar evidências e transformar observações em métricas e hipóteses de melhoria.

## Problema

Resultados de testes frequentemente ficam espalhados entre notas, planilhas e documentos. Este projeto explora uma interface simples para manter a evidência próxima da tarefa e gerar uma leitura rápida dos padrões encontrados.

## Funcionalidades

- Cadastro de participante e tarefa
- Resultado da tarefa: sucesso, dificuldade ou falha
- Tempo de execução
- Contagem de erros
- Classificação de severidade
- Observações qualitativas
- Dashboard com taxa de sucesso, tempo médio e erros
- Identificação do problema de maior severidade
- Síntese automática de uma recomendação
- Persistência local no navegador
- Interface responsiva

## Stack

- HTML5 semântico
- CSS3
- JavaScript puro
- LocalStorage

## Como executar

Abra `index.html` em um navegador. Não há dependências externas nem etapa de build.

## Como este projeto representa UX/UI

O objetivo não é apenas criar um CRUD. A interface foi estruturada em torno do fluxo de pesquisa: **planejar → observar → registrar → medir → encontrar padrões → recomendar**. Isso permite demonstrar arquitetura da informação, visualização de métricas, design de estados, UX Research e implementação front-end.
